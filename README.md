# VampNet-Unloop Workspace

This repository is a local workspace for VampNet, Unloop, setup notes, and related experiments.

## Contents

- `vampnet-main/`: VampNet source code and project files.
- `unloop-main/`: Unloop source code and Max/Python project files.
- `wavebeat-main/`: WaveBeat source code used as a related dependency/reference.
- `Unloop_Setup_and_Model_Guide.docx`: Local setup guide.
- `build_unloop_setup_doc.py`: Script used to generate the setup guide.

## Model Weights

Large downloaded model files are intentionally not tracked in this GitHub repository. Download pretrained VampNet model weights from the original project links documented in `vampnet-main/README.md`.
